합계와 평균 계산

for문과 input으로 여러 숫자를 입력받아 합계·평균 구하기

노트북 내용 보기 
# 코드
count = int(input("몇 개의 숫자를 입력하시겠습니까? "))
total = 0

for i in range(count):
    num = int(input(f"{i+1}번째 숫자를 입력하세요: "))
    total += num

average = total / count
print(f"합계: {total}")
print(f"평균: {average}")

# 실행 결과 (입력: 3개 - 10, 20, 30)

2번째 숫자를 입력하세요:  20
3번째 숫자를 입력하세요:  30
합계: 60
평균: 20.0

Turtle로 사인 곡선 그리기

IDLE에서 math.sin과 turtle 모듈로 사인 곡선 그래픽 그리기

코드 보기 
import math
import turtle
t = turtle.Turtle()
for angle in range(360):
    y = math.sin(math.radians(angle))
    scaledX = angle
    scaledY = y*100
    t.goto(scaledX, scaledY)
