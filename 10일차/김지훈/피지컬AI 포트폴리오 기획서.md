## 3. 웹페이지 구조

**파일 구성**: `index.html`+`style.css`(메인), `1일차.html`~`10일차.html`(일차별), `day.css`(공용 스타일), `script.js`(터미널·애니메이션·메뉴 로직)

**이동 방법**
- 좌상단 "=" 메뉴 → 1~10일차 링크
- 터미널 명령어: `ls`(목록), `n일차`/`cd n일차`(이동), `clear`, `help`, 방향키(기록 탐색)
- 일차 페이지 헤더: 메인 이동 + 이전/현재/다음 일차 내비게이션

**일차 페이지 공통 요소**: 소개 카드, 결과물 카드(`.project-item`, 새 탭 링크), 접이식 코드 보기(`.code-viewer`), 원본 파일명 나열(`.file-list`), 스크린샷(`.content-image`), 하단 시스템 정보

## 6. 개발 원칙

- 정적 사이트(빌드/서버 없음), Claude Code와 대화형 개발
- 학생 코드 원본 그대로 유지(오류 있어도 "미완성" 배지만 표시)
- 코드 보기는 정적 삽입 방식(`file://` 실시간 로드 제약 회피)
- 중복 백업본은 최종본만 표시, "직접 풀이"/"참고 자료" 배지 구분
- 개인 메모 제외, 상위 폴더 탐색 링크 미사용
- 방향이 갈리는 결정은 사전 확인 후 진행

## 7. 기술 스택

HTML5/CSS3/Vanilla JS, Google Fonts(JetBrains Mono, Noto Sans KR), Canvas 2D API. 외부 라이브러리는 각 일차 결과물 내부에서만 사용(예: 9일차 TensorFlow.js+coco-ssd)
