## 3. 카테고리별 심층 분석

### 3.1 범용 챗봇 — ChatGPT의 독주와 Claude의 추격

- ChatGPT는 2025년 8월 기준 미국 생성형 AI 챗봇 시장에서 **60.4%**의 점유율로 압도적 1위를 유지했으며, 일일 프롬프트 처리량은 25~30억 건, 일일 활성 이용자는 약 1억 9,060만 명에 달했다.
- Google Gemini와 Microsoft Copilot이 각각 13.5%, 14.1%로 뒤를 이었고, Claude는 3.5%로 점유율 자체는 낮지만 **전분기 대비 14% 성장**하며 가장 빠른 증가세를 보였다. 기업용 어시스턴트 부문에서는 Claude의 점유율이 2024년 18%에서 2025년 29%로 뛰었다.
- (출처: [views4you 2025 AI Tools Usage Statistics](https://views4you.com/ai-tools-usage-statistics-report-2025/), [commandlinux.com 통계](https://commandlinux.com/statistics/chatgpt-vs-gemini-vs-claude-usage-market-share))

### 3.2 이미지 생성 — Google "나노바나나(Nano Banana)"의 폭발적 확산

2025년 8월 출시된 Gemini 기반 이미지 편집 모델 **Nano Banana**는 하반기 최고의 "바이럴" 사례로 꼽힌다.

- 사진을 3D 피규어처럼 바꿔주는 기능이 SNS에서 폭발적으로 공유되며 **출시 4일 만에 Gemini 앱에 1,300만 명의 신규 이용자**가 유입됐다.
- 이 여파로 Gemini 앱이 일시적으로 앱스토어에서 ChatGPT를 추월하는 순위 역전이 발생했다.
- 11월에는 Gemini 3 기반의 후속작 **Nano Banana Pro**가 출시되며 화제성을 이어갔다.
- (출처: [Medium 기술 분석](https://medium.com/@creativeaininja/mastering-nano-banana-your-complete-guide-to-googles-viral-ai-image-generator-ce16a75ef3d4), [CNBC](https://www.cnbc.com/2025/11/20/google-nano-banana-pro-gemini-3.html), [Google 공식 블로그](https://blog.google/products-and-platforms/products/gemini/nano-banana-google-trends-2025/))

### 3.3 영상 생성 — OpenAI Sora 앱, 역대 최速 확산

9월 30일 공개된 **Sora 2 모델과 틱톡형 소셜 앱 Sora**는 2025년 하반기 가장 극적인 성장 곡선을 그렸다.

| 지표 | 수치 |
|---|---|
| 출시 후 미국 iOS 앱스토어 1위 도달 | 48시간 이내 (16만 4천 다운로드) |
| 100만 다운로드 도달 기간 | 5일 이내 (ChatGPT보다 빠른 속도) |
| 앱스토어 1위 유지 기간 | 약 3주 |
| 핵심 기능 | "카메오(Cameos)" — 본인 얼굴을 학습시켜 등장시키는 영상 생성 |

(출처: [TechCrunch](https://techcrunch.com/2025/09/30/openai-is-launching-the-sora-app-its-own-tiktok-competitor-alongside-the-sora-2-model/), [CNBC](https://www.cnbc.com/2025/10/09/openais-sora-downloads.html), [MacRumors](https://www.macrumors.com/2025/10/09/openai-sora-app-1-million-downloads/))

### 3.4 AI 코딩 도구 — Cursor·Claude Code의 급부상

개발자 대상 설문과 시장 데이터를 보면 하반기 코딩 도구 경쟁 구도가 크게 흔들렸다.

| 도구 | 개발자 채택률(SO 2025) | 특징 |
|---|---|---|
| GitHub Copilot | 68% | 여전히 최대 사용자 수 보유, 그러나 점유율 하락세 |
| ChatGPT (코딩 활용 포함) | 82% | 범용 도구로서 개발 업무에도 최다 활용 |
| Cursor | 18% (설문 첫 등장) | 2025년 매출 성장 속도 최고 수준의 SaaS로 부상 |
| Claude Code | 10% (설문 첫 등장) | 2025년 4월~2026년 1월 사이 사내 도입 6배 증가 |

(출처: [Stack Overflow Developer Survey 2025](https://survey.stackoverflow.co/2025/ai/), [Stack Overflow 블로그](https://stackoverflow.blog/2025/12/29/developers-remain-willing-but-reluctant-to-use-ai-the-2025-developer-survey-results-are-here/), [Gradually.ai Claude Code 통계](https://www.gradually.ai/en/claude-code-statistics/))

### 3.5 AI 브라우저 — Perplexity Comet

- 5월 예정이던 출시가 지연되다 7월 9일 제한적 출시, **10월 2일 전면 무료 공개**로 전환.
- 대기자가 수백만 명에 달할 정도로 "2025년 가장 수요가 높았던 AI 제품"으로 자평될 만큼 화제를 모았다.
- 기반이 되는 Perplexity 검색 엔진은 월간 쿼리 7억 8천만 건(전월 대비 20% 성장)을 처리하며 뒷받침했다.
- (출처: [ppc.land](https://ppc.land/perplexity-releases-comet-browser-globally-at-no-cost-after-three-month-limited-rollout/), [getpanto.ai 통계](https://www.getpanto.ai/blog/perplexity-ai-statistics))

## 4. 종합 결론

여러 지표를 종합하면 2025년 하반기 "가장 인기 있었던 AI 도구"는 관점에 따라 다르게 답할 수 있다.

1. **꾸준한 전체 사용량 기준**: **ChatGPT**가 웹·모바일·다운로드·매출 모든 지표에서 부동의 1위를 유지했다.
2. **하반기 신규 화제성·성장 속도 기준**: Google **Gemini(Nano Banana)** 와 OpenAI **Sora**가 각각 이미지·영상 생성 영역에서 역대급 확산 속도를 기록하며 "가장 화제가 된 도구"로 꼽힌다.
3. **개발자 생태계 기준**: 전통 강자 GitHub Copilot의 점유율이 흔들리는 가운데 **Cursor**와 **Claude Code**가 가장 가파른 성장세를 보였다.

즉, "범용 사용량 1위 = ChatGPT", "바이럴 확산 1위 = Nano Banana·Sora", "코딩 도구 급성장 1위 = Cursor/Claude Code"로 요약할 수 있으며, 단일 지표만으로 하반기 전체를 대표하기는 어렵다는 것이 이번 조사의 핵심 결론이다.
