HTML 코드란?

        
HTML(HyperText Markup Language)은 웹 페이지의 구조와 내용을 정의하는 마크업 언어입니다.

      


      

        

          
기본 구조

          
<!DOCTYPE html>
<html lang="ko">
  <head>
    <title>페이지 제목</title>
  </head>
  <body>
    <h1>안녕하세요!</h1>
    <p>문단 텍스트</p>
  </body>
</html>

        


        

          
주요 태그

          
    
            
  • <h1>~<h6> — 제목 (Heading)
    • 
            
  • <p> — 문단 (Paragraph)
    • 
            
  • <a href=""> — 링크 (Anchor)
    • 
            
  • <img src="" alt=""> — 이미지
    • 
            
  • <div> — 블록 컨테이너
    • 
            
  • <ul> / <li> — 목록
    • 
          

        


        

          
HTML의 역할

          
HTML은 웹 페이지의 뼈대입니다. CSS가 꾸미고, JavaScript가 동작을 추가합니다. 세 가지가 함께 작동하여 완성된 웹 페이지를 만듭니다.

JavaScript 코드란?

        
JavaScript는 웹 페이지에 동적인 기능을 추가하는 프로그래밍 언어입니다.

      


      

        

          
기본 문법

          
// 변수 선언
var name = "철수";
let age = 20;

// 조건문
if (age >= 18) {
  console.log("성인입니다");
}

// 함수
function greet(n) {
  return "안녕, " + n;
}

        


        

          
핵심 개념

          
    
            
  • 변수 — 데이터를 저장하는 상자
    • 
            
  • 연산자 — +, -, ==, &&, || 등
    • 
            
  • 조건문 — if / else로 분기 처리
    • 
            
  • 반복문 — for, while로 반복 실행
    • 
            
  • 함수 — 재사용 가능한 코드 블록
    • 
          

        


        

          
JavaScript의 역할

          
JavaScript는 버튼 클릭, 입력 검증, 애니메이션, API 호출 등 사용자와 상호작용하는 모든 동적 기능을 담당합니다. 브라우저에서 바로 실행됩니다.
