# HTML & JavaScript 학습 웹페이지 제작 프로젝트 계획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | HTML·JS 5일차 학습 정리 웹페이지 |
| 목적 | 1~5일차 동안 학습한 HTML/JavaScript 개념을 한 페이지(또는 페이지 묶음)에 정리하고, 개념별 문제풀이(객관식·주관식)를 통해 복습할 수 있는 웹페이지 제작 |

## 2. 콘텐츠 구성 원칙

각 일차(Day)는 아래 2단 구조를 동일하게 반복한다.

1. **개념 설명 섹션**
   - 배운 문법/태그를 쉬운 말로 풀어 설명
   - 실제 예제 코드 + 코드 실행 결과(또는 스크린샷) 함께 제시
   - 코드에 한글 주석으로 핵심 포인트 표시
2. **문제풀이 섹션**
   - 객관식(4지선다) + 주관식 혼합 출제
   - 문제 아래 "힌트 보기" 버튼 → 클릭 시 힌트 펼침(토글)
   - 정답 확인 버튼 → 정답/오답 여부와 간단한 해설 표시

## 3. 일차별 콘텐츠 계획

### Day 1. HTML 기본틀

**개념 설명 항목**
- `<!DOCTYPE html>` 선언의 의미
- `<html>`, `<head>`, `<body>` 구조
- `<meta charset="UTF-8">`, `<title>` 역할
- 태그의 기본 개념(여는 태그/닫는 태그, 속성)

**문제풀이 구성 (제안: 객관식 3, 주관식 2)**
- 객관식 예: "HTML 문서에서 문자 인코딩을 지정하는 태그는?" (보기 4개)
- 주관식 예: "HTML 문서의 기본 뼈대(틀)를 빈칸 채우기 형태로 완성하시오." → 힌트: "html, head, body 순서를 떠올려보세요."

---

### Day 2. HTML 화면 구현 / 리스트 / 표 / 폼

**개념 설명 항목**
- 리스트: `<ul>`, `<ol>`, `<li>` 차이
- 표 만들기: `<table>`, `<tr>`, `<td>`, `<th>`
- `colspan` 개념(셀 병합)
- `<form>` 기본 구조와 제출(submit) 개념
- input 종류: `type="number"`, `type="range"`, `type="radio"`, `type="checkbox"`

**문제풀이 구성 (제안: 객관식 4, 주관식 3)**
- 객관식 예: "여러 열을 하나로 합칠 때 사용하는 표 속성은?" → colspan / rowspan / merge / span 중 선택
- 주관식 예: "체크박스와 라디오버튼의 차이를 한 문장으로 설명하시오." → 힌트: "하나만 선택 가능한지, 여러 개 선택 가능한지 생각해보세요."
- 주관식 예: "2행 3열짜리 간단한 표 코드를 직접 작성하시오." → 힌트: "tr은 행, td는 칸입니다."

---

### Day 3. HTML 스타일링 / 색상 / nav

**개념 설명 항목**
- 내부 스타일시트(`<style>` 태그, head 안에 작성)와 인라인 스타일(`style="..."` 속성) 차이
- 색상 설정 방법(색상 이름, `#RRGGBB`, `rgb()`)
- `text-decoration` (밑줄, 취소선 등)
- `text-align` (좌/우/가운데 정렬)
- `<nav>` 태그의 의미와 사용 목적

**문제풀이 구성 (제안: 객관식 4, 주관식 2)**
- 객관식 예: "글자 가운데 정렬을 위한 CSS 속성은?" → text-align: center 등 4지선다
- 객관식 예: "내부 스타일시트를 작성하는 위치로 올바른 것은?" → head 안 `<style>` 태그
- 주관식 예: "밑줄과 취소선을 각각 적용하는 text-decoration 값을 쓰시오." → 힌트: "underline과 line-through 중 하나씩 대응됩니다."

---

### Day 4. JavaScript 연산자 / 조건문 / 반복문

**개념 설명 항목**
- 증감 연산자 (`++`, `--`) 전위/후위 차이
- 비교 연산자 (`==`, `===`, `>`, `<` 등)
- 삼항 연산자 (`조건 ? 참 : 거짓`)
- 다중 조건문 (`if ~ else if ~ else`)
- 반복문 (`for`문 구조: 초기식, 조건식, 증감식)
- `break`로 반복문 탈출하기

**문제풀이 구성 (제안: 객관식 4, 주관식 3)**
- 객관식 예: "다음 코드 실행 후 x의 값은?" (증감연산자 코드 제시)
- 객관식 예: "삼항 연산자의 올바른 형태는?" → 4지선다
- 주관식 예: "1부터 10까지 합을 구하는 for문을 작성하시오." → 힌트: "합계를 담을 변수를 반복문 밖에서 0으로 초기화하세요."
- 주관식 예: "반복 중 특정 조건에서 즉시 반복을 멈추려면 어떤 키워드를 쓰는가?" → 힌트: "b로 시작합니다."

---

### Day 5. JavaScript 활용 — 윤년/평년 판별

**개념 설명 항목**
- 윤년 판별 조건 복습 (4의 배수이면서 100의 배수가 아니거나, 400의 배수인 경우)
- 나머지 연산자(`%`)를 이용한 배수 판별
- 다중 조건문 + 논리 연산자(`&&`, `||`)를 조합해 윤년 로직 구성하기
- 입력값(연도)을 받아 결과를 화면에 출력하는 흐름 (입력 → 계산 → 출력)

**문제풀이 구성 (제안: 객관식 3, 주관식 3, 코드형 1)**
- 객관식 예: "다음 중 윤년인 연도는?" (2000, 1900, 2023, 2021 중 선택)
- 주관식 예: "어떤 연도가 4의 배수인지 확인하는 식을 작성하시오." → 힌트: "% 연산자로 나눈 나머지가 0인지 확인합니다."
- 코드형 예: "연도를 입력받아 윤년/평년을 출력하는 함수를 완성하시오." → 힌트: "100의 배수이면서 400의 배수가 아니면 평년이라는 예외 조건을 잊지 마세요."

```
 ├─ Day1 섹션: 개념설명 + 문제풀이
 ├─ Day2 섹션: 개념설명 + 문제풀이
 ├─ Day3 섹션: 개념설명 + 문제풀이
 ├─ Day4 섹션: 개념설명 + 문제풀이
 └─ Day5 섹션: 개념설명 + 문제풀이
```

- 한 페이지 안에서 `<nav>` 메뉴로 각 Day 섹션으로 이동(앵커 링크, `id`+`#`)
- 또는 필요 시 `day1.html`~`day5.html`로 파일 분리 (분량이 많아질 경우)

## 5. 문제풀이 기능 동작 방식 (JavaScript 설계)

1. 객관식: 보기 클릭 → JS로 정답 여부 판정 → 정답이면 초록색, 오답이면 빨간색 표시
2. 주관식: `<input>` 또는 `<textarea>`에 입력 → "정답 확인" 버튼 클릭 → 입력값 비교(간단 채점) 또는 모범답안 펼쳐보기
3. 힌트: 기본은 숨김 상태 → "힌트 보기" 버튼 클릭 시 `display` 토글로 표시 (Day4에서 배운 조건문/이벤트 개념을 실제로 적용하는 지점)
