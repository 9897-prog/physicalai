# 프로젝트 계획서

## 1. 프로젝트 개요

- **프로젝트명**: 기초코드 학습 & 문제풀이 웹페이지
- **목적**: 지금까지 배운 HTML/JS 기초 문법을 정리하여 보여주고, 객관식·주관식 문제를 통해 스스로 이해도를 점검할 수 있는 웹페이지 제작
- **배경**: '피지컬AI 기초반' 수업에서 HTML/JS를 처음 배우는 단계이며, 실무용이 아닌 개념 이해와 복습을 목적으로 함
- **진행 방식**: 개인 진행, Claude와 Cursor AI를 보조 도구로 활용
- **기대 효과**: 배운 내용을 스스로 정리해봄으로써 개념을 다시 한번 확인하고, 결과물 형태로 남길 수 있음

## 2. 학습 목표

- 지금까지 배운 HTML 요소와 JS 기초 문법(변수, 연산자, 조건문 등)을 다시 정리하며 복습
- 정리한 내용을 "설명 콘텐츠"로 구성해보는 경험
- 객관식·주관식 문제를 만들어보며 개념을 스스로 점검하는 형태의 학습 시도
- 코드를 직접 동작시키는 구현보다는, 배운 내용을 "정리하고 설명하는 능력"에 집중

## 3. 페이지 구성

### 홈페이지
- 프로젝트 소개 문구
- 기본코드 설명 페이지, 학습(문제풀이) 페이지로 이동하는 링크

### 기본코드 설명 페이지
- HTML 기초 문법 정리 (태그, 구조 등)
- JS 기초 문법 정리 (변수 선언, 연산자, 조건문 등)
- 각 개념에 대한 간단한 설명 텍스트

### 학습(문제풀이) 페이지
- 객관식 문제 (배운 개념 관련, 보기 제공)
- 주관식 문제 (개념을 짧게 서술하는 형태)
- 문제 수는 분량에 맞게 조정 (예: 각 3~5문제 내외)

## 4. 기술 스택

- HTML, CSS, JS (바닐라)
- 개발 도구: VS Code
- 제작 보조: Claude, Cursor AI

## 5. 작업 일정 (총 2시간)

| 시간 | 작업 내용 |
| --- | --- |
| 0~60분 | 아이디어 결정, 페이지 구성 확정, 문제 내용(객관식/주관식) 및 설명 콘텐츠 초안 작성 |
| 60~120분 | Claude와 Cursor AI를 활용해 실제 홈/설명/문제풀이 페이지 제작 및 마무리 |

## 6. 예상 결과물

- 사용자가 웹페이지에 접속하면 홈페이지에서 전체 구성을 확인할 수 있고, 기본코드 설명 페이지에서 HTML/JS 기초 문법 설명을 볼 수 있으며, 학습 페이지에서 객관식·주관식 문제를 풀어볼 수 있는 3페이지 구성의 웹페이지
- 복잡한 인터랙션이나 동작 구현보다는, 배운 개념을 정리하고 문제 형태로 표현하는 데 초점을 둔 결과물
